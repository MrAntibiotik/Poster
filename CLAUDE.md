# Poster — правила проєкту

## ❗ Головне: мінімум запитів до Instagram і Facebook (Meta Graph API)

Зайві запити до Meta шкодять публікаціям: після них Instagram/Facebook починають відмовляти
(ліміти, «ProcessingFailedError», зависання контейнерів). Тому **кожен запит до Meta має бути виправданий**.

- Перш ніж додати будь-який запит до Graph API / rupload — перевірити, чи не можна взяти дані з бази
  (`post_stats`, `account_stats`, kv) або зробити це рідше. Нові періодичні перевірки — лише з кешем і великим інтервалом.
- **Статистики з Instagram/Facebook немає взагалі** (видалено з коду: `_MetaBase.get_stats/get_views/account_stats`
  повертають порожнє без запитів). Аналітика — лише YouTube. Не повертати без прямого прохання користувача.
- Публікація Instagram: один контейнер, одне завантаження, без автоповторів (`single_attempt`); опитування статусу
  з наростаючою паузою (`POLL_DELAYS`), довга обробка — у фоні рідко (2/3/5/10/15 хв), завислий контейнер — максимум 60 хв.
  Ніколи не вантажити файл повторно в той самий контейнер і не створювати новий, поки старий обробляється (дубль).
- В Instagram — строго одне відео за раз (`ig_wait`).
- Після перезапуску/оновлення перевірка доступів не повторюється, якщо була < 12 год тому.
- Щоденний тест Instagram (`maybe_ig_watch`) — не частіше ніж раз на 48 год; `/igcheck …` — лише за запитом користувача
  (кожен тест створює контейнери — нагадувати про це).
- Обмеження Meta (коди 4/17/32/613/80001+) → `RateLimited`: не стукати до кінця вікна (`blocked_until`).

## Інше

- Користувач спілкується українською; відповіді — українською, просто й по суті.
- Програма на ПК користувача сама оновлюється з `main` — усе, що потрапляє в `main`, за кілька хвилин працює в нього.
  Тому перед пушем: `python -m pyflakes app tests`, `python -m unittest discover -s tests -q`.
- Реліз: підняти `VERSION` у `config.py`, запис зверху в `CHANGELOG.md`, `python tools/make_releases.py`, коміт, пуш у `main`.
- Ніколи не комітити `.env`, `config.json`, `tokens/`, `client_secret.json`, токени. Токени користувач вводить лише в панелі.
- Дані каналів: `channels/main`, `channels/en` (див. `app/core/layout.py`).
