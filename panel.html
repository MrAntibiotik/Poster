        ▶️ YouTube 
        
      
        1. Google Cloud Console → новий проєкт → APIs & Services → Library → YouTube Data API v3 → Enable.
          2. 
        
        2. OAuth consent screen: External, додайте себе в Test users, потім Publish app → In production (інакше вхід злітає кожні 7 днів).
          3. 
        
        3. Credentials → Create credentials → OAuth client ID → Desktop app → Download JSON.
          4. 
        
        4. Завантажте цей файл нижче й натисніть «Авторизувати» — відкриється вхід Google. Оберіть акаунт каналу (якщо канал — бренд-акаунт, оберіть саме його в списку).
        
      
        Google показує попередження або помилку?
        
          
          
        • «Google не перевірив цей застосунок» — це ваш власний застосунок, так і має бути: «Додатково» → «Перейти до … (небезпечно)» → дозволити.
          • 
          
        • «Доступ заблоковано: застосунок не пройшов перевірку» — у OAuth consent screen додайте свою пошту в Test users або натисніть Publish app.
          • 
          
        • redirect_uri_mismatch — створено клієнт типу «Web application». Потрібен Desktop app.
          • 
          
        • Вхід доводиться повторювати щотижня — застосунок у режимі Testing; натисніть Publish app → In production.
          • 
          
        • Відео виходять приватними — обмеження Google для API-проєктів без аудиту; подайте форму «YouTube API Services — Audit and Quota Extension».
          •

        🎵 TikTok 
        
      
        1. developers.tiktok.com → Manage apps → Connect an app.
          2. 
        
        2. Products: Login Kit і Content Posting API (увімкніть Direct Post). Scopes: user.info.basic, video.publish, video.list.
          3. 
        
        3. Login Kit → платформа Desktop → Redirect URI як нижче. У Sandbox додайте свій акаунт як target user.
          4. 
        
        4. Скопіюйте Client key / Client secret сюди, збережіть і натисніть «Авторизувати».

        🤖 Назви й хештеги від безкоштовного ШІ 
        
      
        Для відео без json програма бере кілька кадрів із шортса і просить Google Gemini (безкоштовний тариф)
        придумати назву, опис, хештеги та підписи для TikTok / Instagram. Поки ШІ не підключено або воно недоступне — назва береться з імені файлу.
        У Telegram кнопка «🔄 Перегенерувати тексти» просить у ШІ новий варіант.
        
      
        1. Відкрийте Google AI Studio → Get API key, увійдіть у Google-акаунт.
          2. 
        
        2. Натисніть Create API key і скопіюйте ключ сюди. Картка не потрібна.
        
      
      
        
      
        
        
        
      
        
      
        Налаштування
        
      
      
        
        
        
      
      
      
      
        
      
        Безкоштовний тариф Google має ліміти запитів (кілька шортсів на день вкладаються з запасом).
        Google може використовувати дані безкоштовного тарифу для покращення своїх сервісів — надсилаються лише кадри гри й назва файлу.

        🏷 Тексти для відео без json

        (наприклад «бій_на_прохорівці.mp4» → «Бій на прохорівці»; безликі назви на кшталт «2026-11-10 21-33.mp4» → «WoT — епічний момент 🔥»),
        хештеги — за папкою гри. Перед публікацією назву можна змінити кнопкою «✏️ Ввести назву вручну» в Telegram.
