    💤 Сон між слотами (щоб ПК не працював цілодобово)
    
      
    ПК спить і сам прокидається за кілька хвилин до кожної публікації (і до щоденного звіту).
        Поки шортс чекає на «🚀 Опублікувати» або публікується — ПК не засне. Коли все зроблено, а ПК розбудила програма
        і ніхто ним не користувався, — програма сама приспить його. Якщо ж ви за комп'ютером, він засне за звичайними
        налаштуваннями сну Windows (раджу «Переводити в сон через 30 хв»).
    
      
      
    
        
    
        
    
      
    
      
    🎮 Стрім і гра
    
      
    Поки запущена будь-яка з цих програм — ПК не засне (ні сам, ні через програму). Також у боті є кнопка «🎮 Стрім» — не спати N годин.
    
      
      
      
      
      
    
        
    
      
    Важливо: ПК має бути у сні, а не вимкнений. Кнопку «Дозволити таймери пробудження» натисніть один раз
        (або вручну: Електроживлення → Змінити параметри схеми → Додаткові → Сон → Дозволити таймери пробудження → Увімкнути).
        Ноутбук із закритою кришкою прокинеться лише якщо в налаштуваннях кришки обрано «Сон».
    
    
    
    
    #️⃣ Обов'язкові хештеги
    
      
    Завжди додаються в кінець назви — незалежно від того, що введено в Telegram. Дублі прибираються;
        якщо назва YouTube виходить довшою за 100 символів, скорочується текст, а не хештеги.
    
      
      
      
      
      
    
    
    
    
    ✍️ Підпис каналу
    
      
    Постійний рядок під кожним відео: в опис YouTube і в підписи TikTok / Instagram / Facebook (перед хештегами).
        Наприклад: «🇺🇦 Ukrainian veteran on the road to 1000 subscribers — subscribe to support 🛡️♥️». Порожньо — без підпису.
    
      
      
      
      
    
    
    
    
    🏷 Тексти для відео без json
    
      
    Якщо поруч із відео немає json, програма створить його сама: назва — з імені файлу
        (наприклад «бій_на_прохорівці.mp4» → «Бій на прохорівці»; безликі назви на кшталт «2026-11-10 21-33.mp4» → «WoT — епічний момент 🔥»),
        хештеги — за папкою гри. Перед публікацією назву можна змінити кнопкою «✏️ Ввести назву вручну» в Telegram.

    🇬🇧 Англомовний канал 
    
      
    Окремий канал зі своєю чергою, розкладом і акаунтами (YouTube, TikTok, Instagram, Facebook) —
        напр. для англомовних шортсів з реплеїв. Код спільний з цим каналом, а налаштування, токени й база лежать окремо
        в папці channels\en. Шортси з цієї папки сюди не потрапляють, і навпаки.
    
      
    
        
        
        
    Стартові налаштування: розклад за часом Нью-Йорка (11:00, 14:00, 17:00, 19:30, 21:30), тексти ШІ англійською,
          хештеги #worldoftanks #wot #shorts, підпис «🇺🇦 Ukrainian veteran on the road to 1000 subscribers — subscribe to support 🛡️♥️».
          Публікація спершу лише на YouTube — інші платформи вмикаються в панелі каналу.

    🔄 Оновлення програми 
    
      
    Програма кожні кілька хвилин перевіряє GitHub і, коли нічим не зайнята (нічого не публікується, ви 5 хв не клацали в боті),
        завантажує нову версію й перезапускається. Ваші налаштування, токени, база й журнал не змінюються;
        перед оновленням поточна версія зберігається повністю (папка data\versions).

    🕘 Історія версій

    Доступ до приватного репозиторію
    
      
    Репозиторій приватний, тож потрібен токен GitHub лише на читання:
    
      
      
        
    1. Відкрийте GitHub → Fine-grained token.
      2. 
        
    2. Назва — poster-update, термін — до року. Repository access → Only select repositories → poster.
      3. 
        
    3. Permissions → Repository permissions → Contents: Read-only (більше нічого). Generate token, скопіюйте сюди.
